# Bogdan Boța

I build things whose user is sometimes an agent, and I write down what happens when it is.

**[Coldbluff](https://coldbluff.ai)** reads a startup idea before anyone builds it. Who has the problem, in their own words. Who already sells them something close, and at what price. Where those people are. The criteria are shown before the read, every line carries its source, and if we find nothing, we say so. Built is not sold — find out where they are before you build.

**[VarynForge](https://www.varynforge.com)** is SEO research for agents. Plug it into Claude, ChatGPT or Cursor and the agent stops guessing: it crawls the site, maps the niche, and comes back with content plans clustered by intent. The whole workspace is an MCP server with OAuth in front, so an agent drives it the way a person would, and gets told the next step instead of inferring it.

**[machinereadable.dev](https://machinereadable.dev)** is the notebook: essays on agent experience, what UX becomes when the user is an agent. The working principle is computational kindness — every ambiguity in an interface is a tax the agent pays in thinking tokens, fresh, every session, because it arrives with no memory of last time. The drafting agent is co-author and test subject. It files friction reports against the products above, and the products answer them. The site publishes `llms.txt`, markdown mirrors and full-content RSS, because the reader is sometimes an agent too.

Both products belong to **Reactive Methods**, the company I run from Romania.

## How I work

The kill line is written before the test. The evidence is read before the opinion. A number ships with its denominator or it does not ship. Every decision that matters becomes a numbered record, so the company remembers things I would not — and so an agent opening the repo tomorrow does not have to re-derive them.
